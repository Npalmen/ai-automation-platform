### Summary

Adds the versioned Kapitel 2E gold evaluation dataset and adversarial coverage for AI Receptionisten.

The change expands the deterministic evaluation harness from 10 to 20 curated scenarios and establishes contracts for future Live Gmail, Live LLM and generated high-volume test runs.

### Delivered

- Schema 2e.1
- Authoritative `k2e-v1` dataset manifest
- 20 curated gold scenarios
- 10-scenario smoke set
- Typed forbidden and allowed outcomes
- Deterministic customer-reply quality rubrics
- Executable safety coverage gate
- Scenario and manifest hashing
- Explicit `k2e-baseline-v1`
- Fixture-only enforcement for Kapitel 2E
- Future provenance contracts for:
  - Live Gmail
  - Live LLM
  - AI-generated variants
  - reproducible seeds
  - high-volume evaluation
- Deterministic smoke gate in release workflow

### Scenario coverage

- normal leads

- forced fallback

### Safety properties

- Forbidden outcomes are release-blocking
- Unknown or injected actions cannot execute
- Prompt content cannot grant authorization
- Cross-tenant attempts fail closed
- Unresolved operations cannot retry automatically
- Runtime identifiers are excluded from baseline comparisons
- Baseline writes require explicit authorization and full safety PASS
